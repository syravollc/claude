# Amor Fati: garment design brief v2 (DRAFT)

Status: 2026-10-19. Replaces the approach in V1. V1 produced a single painting dropped onto a shirt, which is not what the user wants. Nothing spent.

## What went wrong in v1 and what v2 does

- v1 treated the shirt as a canvas for one picture. The user's references (streetwear and band merch) are different: the garment is a **system of placed elements** that work together: a main illustration, lettering, small caption blocks, a list of phases, sleeve text, a small chest emblem, and a neck label. Together they carry the meaning.
- v1 chose a "shipwreck" scene, which reads as struggle. *Amor fati* is not enduring a storm; it is **accepting and loving what happens**. v2 uses a calm, dark, aesthetic image of acceptance.
- v1 used a full-color painting. Streetwear prints usually use **2-3 flat inks on a washed black garment**, which also looks more premium and is easier to produce.

## Concept: "The Thread"

From myth, the Fates spin, measure and cut the thread of a life. Amor fati is holding that thread without fear. One red thread runs through the entire piece.

**Two inks on washed charcoal-black cloth:** bone white (#E8E2D4) and oxblood red (#8E1B1B). Distressed, slightly cracked screen-print texture. Engraving or etching line style, not painting.

### Element map (the garment as a system)

| Placement | Element | Content |
|---|---|---|
| **Back, center hit** (about 12 in wide, starting about 3 in below the collar) | Main illustration | Two open hands rising from the bottom edge, palms up, receiving a single red thread that falls from a break in engraved dark cloud above. The thread wraps once around the wrists and rests in a loose, calm knot. Faint radiating engraved lines behind, like a sun cropped by the frame. |
| **Back, above the illustration** | Arched title | AMOR FATI in wide-spaced refined serif capitals (engraved look). The red thread passes through the letters once. |
| **Back, below right** | Caption block | Small: THE LOVE OF FATE |
| **Back, below left** | Phase list, small monospace or condensed type | I. IT ARRIVES / II. IT BREAKS YOU OPEN / III. IT TEACHES / IV. YOU LOVE IT |
| **Left sleeve, outer face** | Vertical micro-text | AMOR FATI · LOVE OF FATE (tiny capitals, bone white) with a red thread line running along the seam |
| **Front, left chest** (about 3 in) | Emblem | A small thread-knot icon in red, nothing else |
| **Inside neck label (print)** | Brand placeholder + line | [BRAND] / FATE IS NOT A WALL. IT IS A THREAD. |
| **Hem, back, optional** | Tiny line | MEMENTO VIVERE (only if the user wants the brand to link phrases; verify Latin first) |

Rules: the red thread is the one consistent element across every piece in the brand. Every future phrase gets its own central image and its own phase list, but keeps the same two-ink, element-map structure so the collection reads as one brand.
