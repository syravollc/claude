# Chapter 10: Using AI and Other Tools Without Losing the Learning

*Draft. General guidance; tools and policies change fast, so verify current terms and age requirements. [VERIFY]*

---

Tools can help a lot, and they can also do the thinking for you. The line is: **use tools to support learning, not replace it.**

## Good uses
- **Planning**: building a schedule, organizing a project.
- **Explaining**: asking for an idea to be explained a different way, then checking it.
- **Practice**: generating extra practice problems or quiz questions.
- **Feedback on drafts**: asking what's unclear in a piece of writing (the student still writes it).
- **Curiosity**: exploring a topic and finding sources to check.

## Risky uses
- Getting answers without trying.
- Having it write the work.
- Trusting it without checking. AI tools can be wrong or make things up. Always verify with a reliable source.
- Sharing private information, including a child's name, age, location or records. Check any tool's privacy terms and age rules. [VERIFY]

## Simple rules for a family
1. **Try first.** Struggle for a few minutes before asking for help.
2. **Explain it back.** If you can't explain it without the tool, you haven't learned it.
3. **Check the facts.** Find a second source.
4. **The work is yours.** The student writes and solves; tools support.
5. **Be honest about it.** Follow the rules of any class or program about tool use.
6. **Protect privacy.**

## For parents
Tools are a good way to reduce busywork, like organizing, planning and drafting worksheets. That frees up time for the human parts: conversations, feedback and encouragement.
